// 02 · Agent Architecture

11 Autonomous Agents.
Zero Consultants Needed.

A hierarchy of specialized agents operating over an async JSON message bus. Every action written to an immutable audit log. Orchestrated by Temporal.io for durable execution and auto-recovery.

Core Brain
AGENT 01
Orchestrator Agent
Central Nervous System
Manages workflow execution order, agent scheduling, retry logic, and state persistence. If any agent fails, Temporal auto-retries with exponential backoff. Maintains global engagement state that all agents read.
Temporal.io LangGraph Redis
Critical
AGENT 02
Ingestion Agent
Document Front Door
Monitors client Dropbox folder, classifies files by MIME type, computes SHA-256 integrity hashes, streams to AES-256 encrypted S3 staging in ca-central-1. Purges raw files after confirmed extraction.
Dropbox API v2 AWS S3 FastAPI
Critical
AGENT 03
Document Intelligence

// 04 · Regulatory Architecture

Canadian Law.
Baked In. Not Bolted On.

Penalties under Quebec Law 25 reach C$25,000,000 or 4% of worldwide turnover. Compliance is not optional — it is the architecture.

PIPEDA
Personal Information Protection and Electronic Documents Act
Explicit consent before any personal data collection or processing
72-hour breach notification to Privacy Commissioner under Section 10.1
Accountability principle documented per client engagement
Cryptographic consent tokens logged with timestamp and IP
Law 25
Quebec Bill 64 — Fully Enforced Since September 2024
Section 14: Granular, explicit consent — blanket consent is non-compliant
Section 17: All Quebec client data in Canadian AWS regions only
Section 12.1: Algorithmic transparency disclosure for AI-generated findings
Penalties: Up to C$25M or 4% of global turnover
CASL
Canadian Anti-Spam Legislation
All platform-generated emails require prior express consent
Communications Scan Agent never sends unsolicited messages
Consent scope explicitly defined and logged per client
AIDA
AI and Data Act (Bill C-27 — Pre-Compliance Architecture)
Human oversight mechanism built into Manager Agent layer
Bias mitigation protocols in all analysis agents
Algorithmic transparency documentation maintained per engagement
Architecture designed for AIDA now — no rebuild required when passed
