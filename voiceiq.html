// 01 · Three-Layer Architecture

Perception. Cognition.
Action. 13 Agents.

The Supervisor Agent orchestrates three specialized layers — each agent is a LangGraph node connected by typed state edges. The entire system runs inside a single real-time call session with sub-500ms response latency.

⟨ Perception Layer ⟩
01
Telephony Gateway
Owns PSTN/SIP layer. Twilio WebSocket Media Streams. Manages call state machine end-to-end.
02
VAD Agent
Silero VAD detecting speech in 20ms windows. Enables barge-in. Filters noise and silence.
03
STT Agent
Deepgram Nova-2 phonecall model. Streams partial transcripts in real time for speculative processing.
04
Emotion Agent
Hume AI streaming. Per-utterance emotion vector: anger, distress, frustration, satisfaction.
⟨ Cognition Layer ⟩
05
Intent Agent
GPT-4o function call classifying intent taxonomy per tenant. Detects sub-intents: ticket, callback, booking.
06
RAG Agent
Pinecone hybrid search + Cohere Rerank. Confidence gating: score <0.65 triggers fallback protocol.
07
Response Agent
GPT-4o streaming. 4-layer system prompt: Persona → Tone → De-escalation → Tool Use. Emotion-adaptive.
08
Memory Agent
Redis active session + PostgreSQL history. Returning caller identification by phone number.
⟨ Action Layer ⟩
09
De-escalation Agent
Activates at anger >0.75 for 2+ turns. 5-step de-escalation sequence. Warm transfer fallback.
10
Tool Agent
Async Celery tasks. ServiceNow, Salesforce, SendGrid, Google Calendar — all without pausing voice.
11
TTS Agent
ElevenLabs Turbo v2.5 streaming. Emotion-adaptive prosody. Barge-in abort in milliseconds.
12
QA Agent
Post-call analysis on transcript. Scores resolution, sentiment trajectory, de-escalation effectiveness.
🎛️
Agent 13 · Orchestrator
Supervisor Agent — The Call Conductor
LangGraph StateGraph conductor managing all 12 agents. Routes outputs via typed edges, monitors health, triggers fallbacks, enforces tenant policies. Makes human transfer decisions at anger >0.8 sustained for 2+ turns.
