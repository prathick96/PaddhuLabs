🎩 Chairman
Round 01
Opening Arguments
Each member presents their opening statement. Bull first, Bear second, Value third, then remaining agents in sequence. Maximum 200 tokens per member. No rebuttals yet.
Round 02
Cross-Examination
Rebuttals only. Each member responds to the single strongest opposing argument from Round 1. No new information may be introduced. Logic and evidence only.
Round 03
Conviction Vote
Final conviction score 0–10 from each member. Chairman reads the full transcript, applies value filter, and issues final verdict. Veto requires written reason with specific principle cited.

// 02 · Daily Pipeline

Two Sessions.
Every Market Day.

Pre-market at 06:30 IST for BUY decisions. Pre-close at 14:45 IST for position review. The system runs on its own schedule — you review the log.

Pre-Market Session
06:30
Wealth Manager activates
Scans overnight news, checks open positions, flags anything requiring immediate attention. Sets session context.
06:45
Market Analyst runs screener
Filters NSE, NYSE, and Crypto universe. Shortlists 3–5 candidates with thesis dossiers. Macro Agent feeds current environment context.
07:00
Council convened on Candidate #1
Bull opens. Bear responds. 3 full rounds of debate. Each member scores conviction 0–10. Street Consensus Agent provides analyst views.
07:20
Conviction score tallied
Requires ≥6/8 to proceed. Below threshold → HOLD logged with full reasoning. Memory Agent checks historical similarity to past debates.
07:25
Buffett Agent reviews
Reads full debate transcript. Applies value + preservation filter. Can veto even 8/8 consensus if it violates core principles.
07:30
Trading Agent executes
Position size = capital × (conviction/10) × risk_multiplier. Security gate → exchange API → Supabase log → Telegram alert sent.
Pre-Close Session
14:45
Wealth Manager reviews positions
All open positions evaluated against current price action and news. Council only reconvenes if a position is down >7% or material news breaks.
15:00
Memory Agent logs session
Full debate transcript, prices, conviction scores, and trade outcomes stored in Supabase pgvector. Portfolio snapshot saved. Next day's screener parameters updated.
